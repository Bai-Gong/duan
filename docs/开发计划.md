# 百工·锻：基础界面开发计划

更新日期：2026-11-05。按用户最新要求，取代此前的转码 MVP 执行计划。

## 目标与范围

锻是 Tauri 桌面工具，界面以简单、清晰为主。参考纸的毛玻璃颜色与层次，不使用宣传首页、大幅装饰、模拟媒体任务或假进度。

本轮只做基础界面。完全舍弃 FFmpeg 路线；等待冶开发完成再接媒体能力，不保留兼容执行开关。

## 整体界面

| 区域 | 内容 | 本轮交互 |
| --- | --- | --- |
| 顶栏 | 应用名、界面预览标识、外观与说明 | 切换浅色/深色，打开说明 |
| 左侧导航 | 转码队列、预设库、界面设置 | 切换页面 |
| 转码队列（默认页） | 素材、输出预设、任务状态、底部汇总 | 真实空状态；添加素材和开始队列禁用 |
| 预设库 | 规划预设卡片、全部/视频/音频分类、搜索 | 分类、搜索、选中详情；不保存或执行预设 |
| 右侧详情 | 当前规划预设、输出格式、保存位置 | 跟随预设选中；输出目录暂不设置 |
| 底部状态 | 当前界面阶段与版本 | 不显示虚假的引擎就绪状态 |

保持纸的浅灰背景、青绿强调色、半透明面板、细边框和柔和阴影；深色同步覆盖。macOS 使用与纸一致的原生 Liquid Glass / sidebar 材质，透明 WebView 与低透明度面板允许系统背景透入；其他平台保留网页面板模糊。左右栏支持拖动分隔线调宽、双击恢复与方向键微调，左栏 160–300px、右栏 220–400px。右侧不放装饰图标。桌面默认 1440×900、最小 1200×760，主区独立滚动；较窄浏览器隐藏详情列。

## 后续接入规则

预设卡片是设计数据，不代表格式已受支持。接入后以冶提供的能力为准，不能将规划预设直接当作可执行参数。页面不直接组装进程命令；未来在独立适配层连接媒体能力，队列状态由真实任务回报驱动。旧实现保留于 Git 历史，不再编译或注册。

本轮不修改用户既有持久化预设，不做格式扩充、编码性能开发、队列调度或文件系统操作。此前联动验收仅为历史记录，不作为当前界面版本的能力声明。
