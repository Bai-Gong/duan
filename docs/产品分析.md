# 百工·锻（Duan）产品分析

> 对标 Adobe Media Encoder · 2026-10-19 留档

## 要做什么

**核心职能**：批量媒体转码的「交付出口」——把各类音视频源统一转出为目标格式。

**必备核心能力**：

1. 多格式导入与解码
2. 主流格式编码输出（H.264/H.265 的 MP4 等）
3. 格式预设体系（内置预设＋用户自建＋收藏）
4. 队列管理（增删、排序、启停、进度与完成提示）
5. 输出路径与命名规则

**可后置高级能力**：监视文件夹自动转码、收录/代理工作流、ProRes/DNx/AV1 等专业编码器与 HDR、字幕嵌入、入出点裁剪、LUT/响度统一、多任务并行、与剪辑工程直连。

## 页面呈现样式

**主界面四大区**：左侧预设浏览器（分类树＋搜索＋收藏）；中部编码队列表格（文件名、预设、输出位置、状态色标、进度条）；右侧或下部的「正在编码」面板（缩略图＋实时进度）；点选队列项弹出的预览监视器（源/输出对比）。

**关键对话框**：导出设置（格式、编解码器、码率、分辨率、音频，可另存为预设）、首选项；监视文件夹为独立面板。

**交互范式**：队列驱动＋后台批处理——拖入素材、套用预设、一键开跑，单项可暂停/跳过/重排，无需盯守，完成状态醒目反馈。
