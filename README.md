# 百工·锻 (Duan)

Tauri + React 媒体转码桌面工具，对标 Adobe Media Encoder。

## 当前阶段：基础界面

2026-11-05 起暂停实际媒体功能，等待百工·冶完成后再接入。界面参照百工·纸的浅灰、青绿与毛玻璃面板，保持桌面工具简洁清晰：默认进入转码队列，左侧导航，中央任务或预设列表，右侧输出概览。

macOS 已采用与纸一致的原生半透明窗口材质；左右侧栏可拖动分隔线调整宽度，双击恢复默认宽度，也可用方向键微调。

右侧详情默认收起，点击组名或「详情」才展开，可关闭。保存目录可手动输入或通过系统选择器选择，当前仅记录路径，不写文件。

已实现：分组队列（新建、命名、移除空组，每组独立选择预设和保存路径，预设库定向应用；仅保留本次会话）、队列空状态、规划预设展示、分类与搜索、选中预设详情、浅色/深色外观、设置对话框。导入、转码、预览与文件保存尚未开放，按钮禁用并显示原因；不生成虚假任务或进度，不修改原有用户预设数据。

FFmpeg 的实现、下载脚本、兼容开关、命令及相关测试已移除。当前桌面外壳不依赖冶、不注册媒体命令。历史媒体实现可从 `52499b1` 及此前提交查看，不作为当前可用功能。

## 开发与检查

```bash
npm ci
npm run tauri dev
npm run build
cargo check --manifest-path src-tauri/Cargo.toml --locked
```

`npm run dev` 用于浏览器界面检查；产品以 Tauri 桌面窗口为准。`npm test` 当前没有测试文件（旧媒体测试随执行实现移除），不代表媒体能力验收通过。Windows 安装包：`npm run package:windows`。

整体规划与接入边界见 [开发计划](docs/开发计划.md)。旧产品研究见 [产品分析](docs/产品分析.md)，其中能力清单不代表当前可用功能。

## 共用毛玻璃主题

公共样式与主题运行逻辑统一来自 `@baigong/fang/glass`、`@baigong/fang/glass.css`（坊 0.1.1）。本仓库只保留布局、既有变量名映射、主题偏好及 Tauri 适配；原生窗口配置仍在 `src-tauri/tauri.macos.conf.json`。

`vendor/baigong-fang-0.1.1.tgz` 是坊 `npm pack` 的固定产物，package-lock 校验内容；可独立检出后执行 `npm ci`，不需要邻近坊源码或跨仓库凭据。公共效果修改应先在坊完成、验证并升级包版本，再同步纸和锻的同一份构建包，不能直接修改 vendor 中的实现。

本轮验证：坊 73 项测试通过，包出口检查通过；两应用 npm ci、前端构建与 macOS Tauri 调试打包通过，实际窗口检查浅色/深色与原生半透明；锻的按需详情与拖拽调宽保持正常。Windows 原生窗口本轮未实机复核。
